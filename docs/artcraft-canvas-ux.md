## Stable usage and mutation rules

- Material Set → 素材灵感板: arrange/compare existing slots; 保存布局 persists only layout. Export/import retains it. Selected insertion uses current slot contents; stale sessions or archived canvases cannot overwrite data.
- Upload/Output image edit and DrawingBoard → 编辑输出版本: choose an original/version, compare or continue editing; every output is a separate existing Output node with lineage. DrawingBoard layers remain editable and unchanged. Its output-edit entry is local-only; existing RH actions still use the established secondary-action/Run authority.
- Sidebar search3D世界 creates the independent node. Import local SPZ/PLY/SPLAT/KSPLAT, orbit/WASD, save views and output a composition. Online generation remains absent. Original mesh preview is untouched. An authorized run of a closed local scene loads on demand, not through a separate provider queue; frozen replay inputs retain its scene and camera.
- Story linked Director/VideoEdit nodes are independent editable drafts. Opening or finishing Story never overwrites existing edits. Explicit 从当前结果新建草稿 keeps prior nodes and reuses media without regeneration.
- Do not remove inert-root guards or permit native remove/select/position edits behind a modal. Identified editing dialogs preserve existing queued API outputs/actions, not just new features; native close-save holds remain strict and use exact one-use approved node objects. Keep archive/backend authority and the original preflight/Run chain. Modal focus must stay inside the active dialog when controls disappear.
