# 桌面内置 Agent 工具与受管导出配套

2026-10-21，采用DSH交接中的问题范围：同为`0.1.0-dev`的源码、桌面内置与旧受管导出内容可能不同，不能跳过精确兼容握手。已随v3.3.9同源双平台发布，六资产独立完整回下载通过，见[发布专题](release-v3.3.9.md)。本轮未改动DSH源码、连接配置、信任pin或真实安装目录。

## 核实与实现

- 原CLI安装器已经按整包内容摘要复制并支持同版本替换，不存在只比较版本号的分支；但画布设置没有DSH提示的安装/修复入口。从旧受管CLI运行自身更新也不会凭空取得新桌面包的文件。
- 设置新增“Agent连接工具”：显示缺失、匹配、内容过旧、受管文件损坏或未受管状态；安装/修复、重新检查和打开配套CLI目录。浏览器不提供导出，挂载/检查不自动安装，重复点击、过期回执和StrictMode effect重放有界。
- 原生入口只接受当前主窗口主frame，renderer不传入来源、目标路径或安装选项。来源固定为当前应用源码或当前`resources`；安装前使用运行后台的同一`compatibilitySnapshot()`逐项核对全部九字段：Skill/CLI、控制/Patch协议、节点、模型目录、能力清单/图谱和manifest摘要。不匹配先拒绝，不替用户选开发源码。
- 从可信内置解析器重新读取来源/导出元数据，不执行旧导出中的检查代码，不因同目录或版本字符串复用旧缓存。同时比较完整CLI+Skill内容摘要和受管文件清单；即使九字段相同，只要代码内容不同也刷新。
- 复用原安装器原子交换与last-known-good；复制期间再核对实际stage整包摘要，变化则在替换前拒绝。已完全匹配时不重装、不冲掉回退副本。修复保留原受管发现副本事务；首次连接工具导出不接管其他Agent的全局Skill目录。未受管/链接目标继续拒绝，配对凭据和用户画布不受影响。
- 导出成功显示`Agent/runtime/<cliVersion>`的实际目录。连接端必须重新检测并由用户明确审阅新内容摘要；不自动改信任、不自动配对、不扩大权限。原CLI mismatch恢复提示指向此流程，已有任务只查询原记录，不因错误响应重交生成。
- `electron/agentTools.cjs`已加入asar必需文件门；前后端、preload、IPC类型、中英文和能力派生文件保持同步。原自动更新真实存储关闭保护不变。

## 交接与边界

1. DSH交接报告已用桌面3.3.7内置CLI完成真实配对；本轮不借用该会话或凭据，不将旧现场报告当作新导出后的验收。
2. 新导出后的真人原生批准最小只读权限、多实例新人流程、完整创作/付费Provider和正式安装升级仍后补，不记为通过。HTTP测试只保留待批状态，授权检查不读取数据库。
3. 旧安装包不会随源码修改而热更新；须实际运行包含本功能的新版，再到设置安装/修复。发布后Tag与产物冻结，源目录工具不能自动配套所有旧安装版。
