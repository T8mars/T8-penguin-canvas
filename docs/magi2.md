# Magi 2 视频模型

视频节点选择「贞贞的平价 AI 小屋 → Magi」。国内版为 `magi-2`，海外版为 `magi-2-global`。请求参数相同，使用平价小屋 API Key。

| 模式 | 输入 |
| --- | --- |
| 文生视频 | 提示词 |
| 首尾帧 | 提示词和 1–2 张图，依次是首帧、可选尾帧 |
| 参考生视频 | 提示词和至少一项素材，最多 10 张图、5 段视频、5 段音频 |
| 自动 | 无素材走文生，只有 1–2 张图走首尾帧，有音视频或至少 3 张图走参考生 |

只有 1–2 张角色或风格参考图时，请显式选「参考生视频」。音频和视频各段为 2–30 秒，各自累计最多 30 秒。输出为单个 MP4，固定 1080p，时长为 4–30 秒，默认 5 秒。比例可选或交由模型决定，首尾帧省略比例时跟随首帧。音轨默认开启，种子 −1 省略，0 会照常传给 API。[官方接口文档](https://api.seedance.nz/docs/llms.txt)
