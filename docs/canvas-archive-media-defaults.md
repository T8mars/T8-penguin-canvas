# 本地画布管理、归档和新建媒体节点默认来源

2026-10-05：开发完成，准备随 v3.2.5 发布。用户要求现有节点不自动换来源；本轮没有付费 Provider 调用，没有读取用户或历史数据库。正式发布事实见 [发布专题](release-v3.2.5.md)。

## 使用方式与范围

- 左侧“管理全部画布”打开独立大窗口，支持工作中/已归档、名称或 ID 搜索、最近修改/最近打开排序、置顶和节点数。窄屏自适应，窗口化渲染；默认每页 50 条，最大 200 条，只打开选中的画布文档，不预载全部节点或缩略图。
- 归档是可恢复的整理状态，不删除、压缩、释放磁盘或搬动媒体。归档画布可以只读查看；明确恢复后才允许编辑/运行，恢复不会自动运行节点。置顶和最近打开属于本机目录偏好，不改变内容修改时间。
- 设置 → 新建节点默认来源：图像（包括图像编辑）和视频分别选择软件默认、AI 工坊、平价 AI 小屋，也可一次把两项设为平价小屋。保存成功以服务端读回为准，展示实际有效默认模型和作用范围。
- 仅空白新建通用 image/edit/video 应用偏好；侧栏、右键/拉线/选区 AI、适用 canvasAgent/Creator 创建入口复用同一合同。现有节点、复制粘贴、导入、模板、历史输入、重试和显式来源/模型保留原配置。Seedance/RH/ComfyUI/Story/MV 等专用或复合节点、音频和 LLM 不因此改来源。
- 未配置平价 Key 不偷偷转到工坊；创建/保存允许，执行仍由既有渠道配置门拒绝。无密钥复制到节点、无跨渠道借用 Key。偏好创建时物化并在计划预览/批准之前冻结，不在提交或恢复时动态读取全局改写。

## 数据与安全合同

`backend/src/shared/mediaNodeDefaultsContract.json` 是 TS/CJS 共用版本 1 初始化合同。两端严格枚举/版本校验，旧缺字段维持软件默认；首次加载失败不猜测默认，刷新失败保留最后验证值；过期加载/保存响应不能覆盖新值。设置 UI 同步捕获事件值，避免 React 事件释放导致丢选择。

归档采用正式 schema33 附加迁移和同库 canonical 目录、profile、操作凭证、轻量投影。schema32 冻结身份及恢复协议保持不变；迁移前有验证的 canonical 备份、空间门、原子事务、完整 DDL/receipt/FK/quick-check，ACK 只前进。迁移失败回滚保留证据，重启可继续。

当前画布归档先冻结编辑/新运行，捕获输入与视口、冲刷待存队列、等最新 ACK；后端同一写入协调门重新检查内容 revision、目录 CAS、项目归属、运行和受理不明状态。忙/保存失败/冲突拒绝，不取消任务、不自动创建空画布。幂等 UUID 对应精确请求，丢响应只恢复同操作；改变请求不能重用凭证。凭证有界且不自动 GC。

普通旧客户端 PUT、CanvasPatch、Creator、新 Run/Intent 受权威 SQL/写入门保护，不只禁用按钮。合法已受理任务仍通过既有 RunAsset 账本按原 canvas/entity/Attempt 接收晚到资产，不改身份或画布 revision。镜像恢复不能将归档复活；批次水化每次 2 条，目录未完整时明确 partial。备份、重启和数据路径迁移保留归档、profile 和凭证。

升级后旧 v3.2.4 程序会拒绝 schema33，不能直接降级打开、删表或手工覆盖库。保留迁移备份不等于自动授权回滚；回退仍需独立验证的安全方案。
