# 2026-11-08 画布反馈修复

状态：开发完成并通过限定验证，尚未打包发布；已发布版本仍为 v3.4.9。本次不改变版本、模型、默认来源、任务提交权限或已发布 Tag。长期外部验收仍为 27/32，F8–F10 保持原边界。

## 功能与根因

| 反馈 | 修复与操作入口 |
| --- | --- |
| 视频剪辑排序与成片不一致 | 旧排序只改变 `clips`，导出读取的时间线位置没变，已实际复现 A/B 调为 B/A 后导出仍 A/B。新增明确的顺序提交：同时更新真实时间线及关联音频，保留裁剪、稳定条目 ID、自定义轨道与间隔。节点卡片新增前移/后移箭头；超过八段可翻页。名称排序和既有拖放回调共用同一入口。 |
| 素材集不移除已拖出上游组的图片 | 原收集只追加、按 URL 去重，且没有记录来源。收集后记录来源条目并持续同步，支持上游清空和断线；手动素材保留，手动移除的上游项不会立即复活。保存/备份保留来源，重复资源槽位按稳定条目身份区分。 |
| 旧素材没有来源记录 | 不猜测其是否手动添加。普通收集只显式认领当前仍能对应的旧项，其他旧项保留；“按上游重建”在用户确认后替换全部内容，包含手动项，得到当前上游的完整快照。只读与反馈回路会阻止重建。 |
| 文本和输出素材的引用链路 | 文本节点可接收分割后的上游文本，默认跟随；编辑后切换本地，断线或切换时保留本地草稿及其引用。输出素材的文本编辑器复用 @素材编辑器，保存引用并正确发布编辑后的文本段，避免下游继续拿到旧分段。混合媒体输出原有的媒体优先转发规则保留。 |
| 拖动第一个输出导致其他输出跟着移动 | 自动网格把第一个输出的当前位置当锚点。现在拖动开始就标记独立位置，重排忽略手动移动/正在拖动的锚点，并从未移动节点反推网格原点；多选拖动语义保留。 |
| 导演分镜台逐条复制脚本、绑定图片繁琐 | 新增“导入上游脚本”和“自动分配图片”。按上游文本和既有分镜标题解析器建立草稿及秒级时间线；支持整秒时长和时间范围，超出当前 4–15 秒约束会明确拒绝，不静默裁短。已有手工脚本、已受理任务和结果保留，重复导入不重复建立相同草稿。 |

图片分配依据明确的素材名/文件名或 `@imageN`，同时支持角色与场景图；重名、缺失引用报告给用户，不做视觉猜测或随机分配。组节点保留分段数量和图片文件名。生成请求中的引用编号按实际提交的图片列表重新编号，已导入的单镜脚本不会再叠加整份上游脚本。上述入口只配置草稿，不提交视频生成任务。

上游同步增加了包含组成员关系的反馈回路检查，避免文本或素材集从包含自身的组中不断回收自己的输出。通用的素材集来源收集使用已保存的条目 ID；没有唯一 ID 的历史异常条目才保留旧下标兼容路径。

- 隔离 ReactFlow 页面挂载真实 VideoEdit、GroupBox、MaterialSet、TextSplit、Output、Text、Director 组件；使用真实连线端口校验。实际点击和拖动验证了排序、八段之后的翻页、图片出组/组清空/重新收集、保留手动素材、上游文本更新、本地草稿恢复、两种文本编辑器的 @图片、两个分镜的 5/6 秒时间线和对应角色/场景图片。

原始证据在 `local-private/video-edit-order-20261108/`：`compose-report.json`、`ui-report.json`、成片及四张界面截图；最终回归与类型检查日志分别为 `local-private/user-feedback-final-regressions.log`、`local-private/user-feedback-final-typecheck.log`。
