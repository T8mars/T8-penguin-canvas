# 代码动画：开发完成

2026-10-26完成开发后，用户追加授权v3.4.4打包发布；实际发布进度见[发布专题](release-v3.4.4.md)。以下开发证据不代替安装升级和用户现场。原始协议研究与设计见[规划](motion-video-node-plan.md)。

## 使用

从节点菜单添加“代码动画”（`code-animation`），在右上角API设置填写贞贞的平价AI小屋Key。节点可使用本地描述，或连接上游文本；新建时上游优先。现有“运镜提示词”节点不变。

- 模型：`zhenzhen/motion-video`、`zhenzhen/motion-video-pro`。
- 时长15/30/45/60秒，比例16:9/9:16/1:1，720p/1080p；默认标准版、15秒、16:9、720p。
- 十种已核实风格；标题、副标题、逐行关键词、署名、语言和配乐为可选项。空值省略，署名留空可能采用平台默认署名。
- 放大工作台中查看视频、分镜、历史版本；选择任意成功版本后点击“修改此版本”，填写独立修改要求。修订沿用所选版本的模型与规格，会产生新的任务及费用。
- “以这些设置新建”回到生成模式；停止等待后保留旧成片与原任务查询入口。提交受理不明时不自动重发。
- 分镜跳转是累计时长估计。替代场景、祖先降级提示、用户审阅记录分别保存；服务未报告替代场景不等于画面已经完全合格。

## 生产实现

| 范围 | 接入 |
| --- | --- |
| 节点发现 | 共享schema、命名端口、Canvas映射与默认值、类型、菜单、落点、中英文、CLI能力产物与digest同步；85个节点均有能力归属 |
| 请求 | `motionVideoContract.json`统一模型/枚举；`motionVideoContract.js`仅构建官方字段；seedanceNz创建/查询适配，修订先只读检查原任务完成及模型 |
| 执行 | 手动与批量共用`useRunTrigger`和既有RunIntent→Run→NodeRun→Attempt；没有另建付费账本。媒体时限复用最低15分钟合同 |
| 恢复 | 受理后保存原taskId、精确模型、非敏感连接指纹与冻结输入；停止/重启后只GET原任务。下一次草稿改模型不改变正在恢复的模型；连接变化须先只读验证 |
| 保存 | 共享可信下载器、完成记录、字节/格式/散列与CAS资产提交；分镜/质量附属记录同时校验任务、模型、连接和媒体散列；附属信息异常不否决有效视频 |
| 历史 | 共享输入档案及资产元数据还原版本；分页查询保留旧版审阅和选择。当前节点不递归保存旧版本；下游档案保留选中视频/分镜与稳定资产引用 |
| 传递 | video与storyboard端口分离，不泄露生成草稿；Relay/GroupBox/Output及通用上游收集保留代码动画有序视频槽和稳定资产ID，完整元数据在资产上回查 |
| 界面 | 懒加载工作台、单播放器、点击播放、离屏暂停、滚动布局、Esc/输入法和焦点归还；归档只读，删除/离开原画布后不向替代实体写回结果 |

核心源码：`CodeAnimationNode.tsx`、`features/motion-video/`、`motionVideo.ts`、`executeMotionVideo.ts`、`motionVideoHistory.ts`；后端提交/查询沿`routes/proxy.js`。后台恢复沿共享`runRecovery`，不在重试保存时重新生成。
