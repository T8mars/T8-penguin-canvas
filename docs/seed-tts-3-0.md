# Seed-TTS 3.0

在画布中打开「音频 → Seed Audio」，选择 `bytedance-seed/seed-tts-3-0`。其他模型、默认选择和现有连线保持不变。

- 朗读本地或上游文本，最多 5000 字符；不接收图片、视频或参考音频。
- 可选音色短名或完整 ID、最多 1000 字符的朗读指令、0.5–2 倍语速。留空使用上游默认音色 `sarah` / 语速 1.0。完整音色目录见[平价小屋官方 API 文档](https://api.seedance.nz/docs/llms.txt)的「Seed-TTS 3.0 语音合成」一节。
- 单条 24 kHz 单声道 WAV，使用既有音频提交、原任务 GET 恢复和结果落盘路径；不重新提交生成来补取结果。

[导入工作流](workflows/seed-tts-3-0.json)：一个音频节点连接一个输出节点，包含试听文本、完整音色 ID、朗读指令和 1.1 倍语速。不含凭据、任务 ID 或生成结果链接。

## 已验证

2026-11-28 核对官方文档和本地 ComfyUI_Seedance（未找到该精确模型的现成实现）。用真实 API 确认目录有精确模型 ID。一次提交及同任务查询均为 HTTP 200；共用下载链路落盘 WAV，FFmpeg 完整解码 57,015 个单声道样本（2.38 秒、114,074 字节）。未重复触发生成。实网结果摘要和试听 WAV 在 `local-private/seed-tts-3.0-20261128/`，不进入版本控制。

71 项定向回归通过，包括工作流导入、中英文控件、既有 Seed Audio 模型顺序、参数边界和本地路由冷恢复。冷恢复测试只查询原任务，输出 WAV 与夹具逐字节一致。
