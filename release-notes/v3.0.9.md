# T8 Penguin Canvas v3.0.9

本版修复核心目录开发启动限制，并把画布性能模式入口整合到顶部控制条，避免浮动控件遮挡终端和画布内容。

## 开发启动稳定性

- 核心目录可以在当前已连接分支直接启动开发环境，不再强制切换到另一条 `codex/*` 开发分支。
- Windows 启动器只处理 11422 / 18766 的本地监听者和可识别的旧 T8 开发进程树，忽略远端连接、`TIME_WAIT` 与 PID 0，避免旧后端占用端口导致前端不启动。
- 后端健康检查仍先于前端启动；安全清理失败时明确停止，不继续启动半套环境。

## 画布性能控制

- “自动 / 高性能”入口移动到顶部画布工具条的最后一位，紧邻终端按钮，不再悬浮遮挡最后一个工具。
- 当前模式使用青绿或琥珀状态色、轻量光晕和状态点提示；窄屏自动收缩为图标，白天/黑夜主题均复用主题变量。
- 弹层固定从按钮下方展开，支持点击外部或按 Esc 关闭；切换模式后自动收起，并提供正确的可访问性状态。
- 系统启用“减少动态效果”时关闭所有装饰动画，不影响文字和模式状态。

## 兼容性与证据边界

v3.0.8 及更早的节点、Provider、默认渠道和模型、旧画布、历史工作流、主题、双语、MiniMax Music3、Windows/macOS 与火山素材能力均保持不变。反馈用户安装、多端协作、F8-F10 与安装升级证据按用户授权在发布后补充；测试、构建、加密、运行时、`app.asar` 启动合同、NSIS、provenance、sealed recovery、固定 Tag/target、自动更新资产和远端完整性技术门禁不得延期。
