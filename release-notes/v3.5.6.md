# v3.5.6 · Magi 视频模型

- 视频节点在贞贞的平价 AI 小屋新增 **Magi**，包含 `magi-2` 和 `magi-2-global`。
- 支持文生、首尾帧、混合参考，固定 1080p。仅使用一两张角色参考图时，请选择「参考生视频」。
- 随附六份可导入工作流。国内文生与海外混合参考均已实网出片并完整解码。[工作流和验证记录](https://github.com/T8mars/T8-penguin-canvas/blob/v3.5.6/docs/magi2.md)

Windows x64 提供 NSIS 安装包和自动更新。Apple Silicon Mac 资产在同一 Release 提供 ad-hoc 签名预览，未经过 Apple 公证。
