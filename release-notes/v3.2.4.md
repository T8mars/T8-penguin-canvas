# T8 Penguin Canvas v3.2.4

## Seedream V5 Flash 六模型

- 原有 Seedream Tab 加入国内 `seedream-v5-flash-t2i/i2i` 与海外 `dola-seedream-5.0-flash-t2i/i2i`，根据实际参考图选择文生图或图生图；不新增重复 Tab，Pro 默认与旧画布保持不变。
- Flash 普通生成支持 5–5000 字符提示词、1K/1.5K/2K 或 240–8192 整数宽高；图生图支持 1–10 张有序 PNG/JPEG/WEBP 参考图，每张最多 30 MiB。Pro 保留原提示词、分辨率和上传限制。
- 原有 Seedream分层 Tab 加入国内与海外 Flash 分层，接收恰好一张源图、可选最多 2000 字符提示词，支持 auto/1K/1.5K/2K 与 PNG/JPEG；底图和所有图层按原序完整保存，不去重或截断。
- 保存六份无凭据工作流；共享模型系列、RunIntent 身份、历史输入及恢复合同，媒体超时最低 15 分钟，受理不明或下载失败不重交付费任务。

## 结果下载与验证

- 可信腾讯 COS HTTPS 结果在网络类失败后尝试官方等价域名 GET，保持对象路径与查询，剥离跨域请求头凭据；不关闭 TLS、不放宽普通非受信 URL、不对取消或 403 重试生成。
- 六个授权真实任务均 HTTP 200 / succeeded，13/13 张图片完整下载、解码并逐张查看；同一 COS 对象的官方别名只读下载 SHA-256 一致。15 套专项及相邻回归 263/263、类型、双语与能力同步检查通过，详见 `docs/seedream-v5-flash.md`。
- 完整继承 v3.2.3 及之前能力、默认值和数据保护；用户安装升级、旧画布、真实设备及 F8–F10 按 `owner-approved-post-release-v3.2.4` 后补，不记通过。
- Windows 正式构建和稳定自动更新不得延期；Mac仅在 GitHub 额度不足时暂缓，仍为 ad-hoc 签名、未公证技术预览。
