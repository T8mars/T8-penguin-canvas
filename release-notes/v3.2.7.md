# 贞贞的无限画布 v3.2.7

## 更新内容

- 右上角“设置 → 启动诊断”新增“保存启动日志”。桌面版可选择保存位置并导出本次及上次启动的阶段计时，方便反馈启动卡顿，不需要寻找应用数据文件夹。
- 自动记录现有 Electron、后端、数据库和前端启动阶段；前十五分钟记录前端长时间无响应的计时标识。采用固定字段、数量限制和异步落盘，不保存 API Key、令牌、路径、画布名称/内容、素材或错误堆栈。
- 保存取消、失败和重复点击分别处理。网页模式明确只导出本次前端日志，不冒认为完整桌面日志。

## 验证与边界

本版仅新增日志诊断功能，没有修改数据库迁移/恢复、画布加载或历史名称，也没有宣称已修复启动慢。请受影响用户升级后，等待启动完成，进入设置保存日志并发给作者，以便继续分析。

本地日志专项17/17、相邻回归36/36通过；原生对话框、用户安装升级、反馈现场与 F8–F10 证据按维护者授权后补，不算通过。正式安装包与自动更新资产仍必须通过完整校验。

## 安装

Windows x64 提供 EXE、blockmap 和 `latest.yml`。macOS Apple Silicon 同源包完成后提供 DMG、ZIP 和 `latest-mac.yml`；仅实际 GitHub 额度不足可延期。

Mac 使用 ad-hoc 完整性签名，未使用 Apple Developer ID、未公证。首次安装请在 Finder 中右键应用并选择“打开”。
