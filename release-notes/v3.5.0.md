# v3.5.0 · 画布协作体验与模型更新

- 视频剪辑增加前移/后移与翻页，排序同步真实时间线及关联音频，修复成片顺序不一致。
- 素材集持续同步上游组，移出组的图片随之移除；保留手动素材，旧快照可确认后重建。
- 导演分镜台支持批量导入上游脚本、生成时间线，并按素材名或 @imageN 分配角色/场景图片。
- 文本节点可接收上游分割文本，输出素材支持 @图片；修复拖动首个输出时其他输出跟着移动。
- 图像模型分类改为下拉列表，Kling4型号分组置顶，并补齐后端型号身份。
- 七类核心节点空白新建默认平价小屋，可分别设置；旧节点、复制/导入和明确偏好保持原配置。
- G2.6 LowPrice支持1K/2K/4K、最多16张静态参考图；GIF按最新协议改为仅文生，保留原始动图。
- 既有Kling/Veo分类接入 zhenzhen-video-kling-v4-flash、zhenzhen-video-g-omni-1.2-flash-lowprice；使用各自参数合同。九份无凭据示例已保存。
