# v3.4.1 · 自动更新关闭补修

- 修复画布确认保存后仍探测后台、触发断线恢复和发送新API请求的漏洞，避免更新退出期间重连已停止或被复用的后台端口。
- 保存阶段仍允许原写入完成；已接受请求不取消。保存被拒绝或取消关闭后恢复访问，冲突内容不自动覆盖。
- 保留真实存储关闭确认、有界等待、失败日志导出/显式重试及安装器不强杀策略；节点、模型、旧画布与Agent权限不变。

源码47项专项/相邻回归、两项真实Electron/临时SQLite/更新器组合及类型检查通过。完整受影响用户现场自动升级与外部设备证据后补，不将手动结束旧版视为正常自动更新验收。

已经卡在旧版保存界面的进程不会因下载本包自动获得新代码；请先保存/导出本地修改，再正常退出并运行完整安装包，勿删除用户数据。

Windows x64；Mac Apple Silicon如发布仍为ad-hoc签名、未Apple公证的技术预览，详见[补修说明](https://github.com/T8mars/T8-penguin-canvas/blob/main/docs/auto-update-close-hold-20261021.md)。
