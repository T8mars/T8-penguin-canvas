# T8 Penguin Canvas v3.2.0

## 新增

- 图像节点新增独立 `Qwen 2.1` Tab，接入 `qwen-image-global-2.1`，支持文生图、0–10 张有序参考图、1K/2K/4K、8 种官方比例与可选 Seed。
- 视频节点新增独立 `Animate Motion Transfer` Tab，使用 1 张角色图 + 1 个动作视频，完整提供官方分辨率、比例、帧率/帧数、姿态、镜头、遮罩、表情和胸部动作参数。
- 新增 Qwen 文生图/图生图、Animate 本地素材/公网 URL 四份无凭据工作流。

## 可靠性与兼容

- 两模型复用现有 Seedance.nz 凭据、共享 15 分钟媒体边界、同任务轮询/重启恢复和受信 Provider 结果落盘，不重放受理不明的付费提交。
- Qwen 2.1 不混入 Qwen Image 3.0 的 `size / n / negative_prompt / prompt_extend`；Animate 不发 Prompt、Seed 或音频。
- 保留 v3.1.9 及更早全部节点、模型、默认值、Provider 协议、工作流和已保存画布。

## 验证边界

- 三条真实 Provider 任务均到达 `succeeded`；Animate 结果已下载并解析为 H.264 / 480×848 / 2 秒。Qwen 两次已成功任务的当次本地 Node 下载遇到 TLS 断开，遵守禁止重复计费规则未重新提交。
- 受影响用户、安装升级、外部设备及 F8–F10 证据按 `owner-approved-post-release-v3.2.0` 后补，不记为通过。Windows 正式构建、自动更新资产和远端完整性不可延期；Mac 仅在 GitHub 额度不足时可延期。
