# T8 Penguin Canvas v3.0.0

本版把官方即梦 CLI v1.4.17 和 Seedance 2.5 完整接入画布外部 Provider。现有默认渠道、默认模型、旧画布、全部 81 个节点、MiniMax Music3、FlashVSR、Hunyuan 3D、Grok、Lyria / Flow Music 及 v2.9.9 和更早能力全部保留。

## 即梦 CLI v1.4.17

- 外部 Provider 兼容版本升级为官方 v1.4.17，协议依据官方飞书指南、官方安装包附带 Skill 和实际命令帮助逐项核对。
- Seedream 5.0 Pro 分辨率更新为 1.5K / 2K / 4K，不再显示不受支持的 1K；Seedream 3.x 保持 1K / 2K。
- 图生图支持 1–10 张有序参考图，不再把多张参考静默截断为一张。

## Seedance 2.5

- 新增模型 `seedance2.5`，覆盖文生视频、图生视频、首尾帧视频和全能参考四种官方命令。
- 输出支持 4–30 秒、480P / 720P / 1080P。
- 全能参考最多 30 张图片、10 个视频、10 个音频，合计不超过 50 个；支持纯音频输入和空 Prompt。
- 智能多帧继续使用官方固定模型，只接受 2–20 张图及 720P / 1080P，不与 Seedance 2.5 混用。
- 保存 5 份无 API Key 配套工作流：文生、图生、首尾帧、全能参考和纯音频。
