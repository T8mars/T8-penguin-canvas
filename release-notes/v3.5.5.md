# v3.5.5 · 长图、语音、视频与 3D 模型扩展

- **图像**：Kling Image 新增长图模型，支持电商详情页和网页设计。网页模式可分别指定风格图和主体图。
- **音频**：新增 Gemini 2.5 TTS 分类，包含 Flash 和 Pro，提供 30 种音色并输出 WAV。
- **视频**：Minimax H3 Lowprice 新增 WF、JY、角色替换和数字人四个 Token 模型。新增 HeyGen Avatar 6 分类，包含标准和 Turbo 两档，支持台词或音频驱动。
- **3D**：新增 Miora 3D 分类，支持文生、单图和多视图输入，保留主模型、归档、材质和贴图。
- 保存 14 份可导入工作流。8 个模型已有真实结果下载与解码证据，HeyGen 两档的原任务仍待成片。[工作流和验证记录](https://github.com/T8mars/T8-penguin-canvas/blob/main/docs/nov21-models.md)

Windows x64 提供安装包及自动更新。Apple Silicon Mac 版为 ad-hoc 签名预览，未经过 Apple 公证。
