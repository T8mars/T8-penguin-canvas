# v3.4.0 · Agent活动画布定位

- 新增只读`zcanvas workspace active`及版本化活动上下文API，返回当前实例的窗口、项目、画布ID、已确认revision和就绪状态。
- 多窗口无唯一焦点时返回歧义候选；加载、重载、崩溃、关闭、保存退出及自动更新准备期间不冒认旧画布已就绪，不默认取目录第一项。
- 保持既有`workspace current/use`的Agent目标选择、精确兼容握手及人工配对/批准；不读取节点正文、素材地址或凭据，不增加写入或生成权限。
- 配套CLI命令目录与桌面同步。升级后可在设置的“Agent连接工具”安装/修复，再在连接端重新检测并明确审阅新目录。

限定回归87项、Electron打包合同16项及类型检查通过；含隔离真实Electron窗口验证，不代表正式安装升级、DSH现场接入或真人批准已验收。现场证据后补。

Windows x64正式包；Mac Apple Silicon如发布仍为ad-hoc签名、未Apple公证的技术预览，首次安装请按系统提示允许打开。详见[活动上下文合同](https://github.com/T8mars/T8-penguin-canvas/blob/main/docs/agent-active-context.md)。
