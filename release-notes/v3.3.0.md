# v3.3.0 自动更新保存与退出修复

- 更新先确认画布保存并等待后台和存储关闭，再启动安装器，避免安装与正常退出竞态。
- 新 Windows 安装器等待精确主程序正常退出，不再强杀；仍在运行或检测异常时分别提示重试/取消，安装器本身不算画布进程。
- 准备阶段禁止重复安装、检查或下载；保存受阻、后台关闭失败及安装器启动失败均明确提示，不自动重试或恢复已停止后台的编辑。
- 保留所有现有画布、数据、模型和历史版本资产。用户截图中的通用卸载/文件复制错误尚未现场复现，不宣称所有安装故障已根治。

70 项修复与相邻测试通过（含临时目录真实 NSIS 编译执行，不等于完整安装验收）。安装升级、反馈用户现场与 F8–F10 按 owner-approved-post-release-v3.3.0 后补，不视为通过。

Windows x64 提供 EXE、blockmap 和 latest.yml。macOS Apple Silicon 同固定源码和正式 Tag，仍为 ad-hoc 签名、未 Apple 公证预览；只有 GitHub 额度不足才延期。
