# T8 Penguin Canvas v3.0.5

本版修复 v3.0.2–v3.0.4 公开 Electron 包可能在 Windows 与 macOS 启动时缺少主进程国际化依赖的问题，同时修复恢复已缩放上传节点后 RUN 操作栏和连线端点偏离可见卡片，并把白模预演同步到 `monoform-previs-studio` v0.6.0。v3.0.4 及更早的节点、Provider、默认渠道、默认模型、画布、工作流、主题、双语和性能能力全部保留。

## 紧急修复：Windows/macOS 启动依赖

- Electron `build.files` 显式包含 `electron/i18n.cjs` 与 `electron/i18n-catalog.json`，修复主进程启动时报 `Cannot find module './i18n.cjs'`。
- 新增静态 CommonJS 相对依赖闭包检查；入口新增本地 `.cjs`、`.js` 或 `.json` 依赖但未进入安装包时，测试会失败关闭。
- Windows 与 macOS post-build 共用 7 项 `app.asar` 启动合同，必须包含主进程、preload、loader、系统网络桥、国际化模块、国际化目录和 `package.json`。
- Windows 安装包与真实 `macos-15` Apple Silicon 包必须从同一个固定 v3.0.5 Tag 构建并进入同一 Release；摘要与回下载之外，还要通过安装包内部启动合同。

## 修复：RUN 操作栏与连线端点偏移

- 操作栏以实际渲染节点和 ReactFlow 根元素的 DOM 矩形为权威锚点，模型坐标仅用于首帧回退；缩放、移动和 ResizeObserver 变化会触发重新测量。
- 已保存的上传节点宽高会在恢复画布时同步用于可见卡片，避免 ReactFlow 外层仍是旧宽度、内部卡片却回到 260px 形成“幽灵边界”。
- 操作栏右边界、节点可见边界和连线端点继续随 viewport zoom 一致缩放；新节点默认尺寸、旧画布数据和用户拖角尺寸不迁移。

## 白模预演 v0.6.0

- 固定同步 `GuiYi-Xi/monoform-previs-studio@daa54b2f6e78cc69f07102f7d32f6fabe3ac4a54`，支持最多 30 个镜头以及镜头级独立场景、人物、摄像机、灯光、参考图、关键帧和缩略图。
- 时间轴支持每镜 1–60 秒、24/25/30 FPS 与循环播放；人物增加动作预设、连续动作、动作相位、角色状态关键帧、自定义姿势、足底锁定和完整骨骼编辑。
- 增加参考图覆盖与导出、光照/曝光、自由相机与角度校正、世界/局部坐标、吸附、落地、比例缩放、3:4 和自定义画幅。
- T8 的节点端口、项目级持久化、Run/STOP、静帧/动态 H.264 输出和 Seedance 参考素材链路保持不变。

## 平台与证据边界

- Windows x64：NSIS 安装包、blockmap、`latest.yml`。
- macOS 12+ Apple Silicon：DMG、ZIP、`latest-mac.yml`。未配置 Developer ID 时为 ad-hoc 签名技术预览，首次打开需在 Finder 右键选择“打开”；Intel Mac 暂不支持。
- 用户授权先发布，反馈用户安装、多设备协作、F8–F10 与安装升级证据按 `owner-approved-post-release-v3.0.5` 后补，延期不等于通过。测试、构建、加密、运行时、app.asar 启动合同、NSIS、provenance、sealed recovery、固定 Tag/target、Windows/Mac 自动更新资产完整回下载和 Latest 等技术门禁均不可延期。
