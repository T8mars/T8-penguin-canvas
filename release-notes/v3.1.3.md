# T8 Penguin Canvas v3.1.3

本版完整保留 v3.1.2 及更早全部节点、模型、工作流、Provider 协议、MiniMax Music3、Veo Omni 1.1、多语言本地化大师、默认渠道和旧画布数据，重点修复 Creator Agent 首次启动时序与连续创作体验，新增权威画布稳定后显示的活动海报，并加入 Hailuo H3 Max 两个视频模型。

## 新增与更新

- Creator Agent 只在当前项目、活动画布、权威 revision 与 ReactFlow 初始化全部属于同一画布后挂载；画布仍在恢复、切换或加载失败时不会抢跑会话与模型请求，避免首次打开直接出现“操作没有完成”。
- Creator Agent 保持宽屏自然对话和三个真实 LLM 建议；回复进行中仍可准备下一轮文字、附件与画布引用，草稿按对话隔离，历史搜索与最新回复定位更稳定，已删除的画布引用会在发送前清理。
- 上传的 PDF 与文本型资料可在受控边界内提取有界文本，并带来源标记进入真实 LLM 上下文；空文件、超限、不可提取内容和不支持格式明确失败，不向模型传递本机路径、凭据或原始 Provider 响应。
- Creator 专用 API 设置聚焦到所需凭据，补齐键盘焦点圈定、Esc 关闭、背景对话隔离和关闭后焦点返回，设置层不再与创作对话抢键盘。
- 新增启动活动海报。它会等待当前项目、活动画布、权威 revision、ReactFlow、可见节点和海报图片全部稳定后才出现，不会在画布尚未加载时显示黑框；单海报隐藏多余导航，多海报支持滚轮、拖动、触控和键盘切换。整张海报与“立即体验”均受控打开在线画布，勾选后对当前 Electron 版本精确 7 天不再显示，升级版本后立即重新展示。
- 贞贞的平价AI小屋 Hailuo TAB 新增 `hailuo-h3-max-t2v` 与 `hailuo-h3-max-i2v`：提示词必填、5–15 秒、480P/768P；T2V 使用六种固定比例且不接受素材，I2V 必须首帧、可选尾帧且不发送比例。两份无凭据工作流随版提供。

## 已核实

- Hailuo H3 Max 两模型各只提交一次真实任务，均完成终态、下载、FFprobe 与 FFmpeg 全片解码；T2V 输出 832×480、5.184 秒 H.264 MP4，I2V 输出 480×480、5.184 秒 H.264 MP4。
- Creator 首次启动已在隔离真实浏览器验证：画布权威状态就绪后才出现入口，对话、六阶段和输入区正常，控制台错误为 0；临时项目数据和测试进程均已清理。
- 启动海报已在独立临时数据库和全新 Chrome 中验证：首次进入 DOM 时 12/12 个预置节点均已渲染、2048×1536 海报已完成加载解码，桌面与移动布局无溢出，真实指针点击成功打开在线画布且浏览器错误为 0。
- 正式发布前低资源串行回归 221/221 通过：前端/启动海报/Hailuo/API 设置 65/65，Creator Electron 运行时 111/111，Electron/更新器/macOS/运行时/发布合同 45/45；TypeScript、4413 个双语键、83/83 节点能力同步、公开源码与 2,949 模块生产构建均通过。

Windows 正式包必须通过私有前后端、后端加密、双运行时、Electron 原生依赖、NSIS、`app.asar` 启动合同、自动更新清单、provenance、sealed recovery 和远端完整回下载；macOS Apple Silicon 必须从同一固定 Tag 在真实 macOS arm64 runner 构建并进入同一 Release。
