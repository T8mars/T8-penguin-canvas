# T8 Penguin Canvas v3.0.6

本版在不回退 v3.0.5 及更早功能的前提下，安全整合 GitHub PR #28 中火山引擎素材节点的任务恢复能力。

## 新增与修复

- 火山素材公网 URL 导入现在创建可跨应用重启恢复的持久任务。
- 任务账本最多保留 100 条脱敏记录；不会保存来源 URL、AK/SK、签名预览地址、完整 Provider 响应或本机路径。
- 仅在节点存在未完成任务时进行最多 20 次、每 2.5 秒一次的短时按需轮询，并提供手动任务刷新；不会创建进程级常驻轮询器。
- PR #28 旧版 `volc-asset` 画布节点会迁移为稳定核心类型 `volcengine-assets`，保留配置档、项目、素材组、已选素材、类型与标签，不会在侧栏生成重复节点。
- 保持火山 HMAC 签名的规范 Host 参与签名、实际 Chromium 请求不显式发送 `Host` 的兼容边界。

## 安全边界

PR 中可从用户可写目录任意 `require()` 的 CommonJS 插件宿主、绝对存储路径回显、来源 URL/Provider 响应持久化和全局常驻轮询没有进入本版。

## 兼容性

默认渠道、默认模型、旧画布、历史工作流、Electron 启动修复、画布几何、白模预演、主题、双语、MiniMax Music3 和全部既有节点保持不变。

## 证据边界

反馈用户安装、多端协作、F8-F10 与安装升级证据按用户授权在发布后补充；测试、构建、加密、运行时、`app.asar` 启动合同、NSIS、provenance、sealed recovery、固定 Tag/target、Windows/macOS 自动更新资产和完整远端回下载技术门禁不得延期。
