# v3.5.8 · Seed-TTS 3.0 语音合成

- 音频节点的 **Seed Audio** 新增平价小屋模型 `bytedance-seed/seed-tts-3-0`。旧模型、默认选项和已有连线不变。
- 支持朗读本地或上游文本，可填音色短名或完整 ID、朗读指令和 0.5–2 倍语速；输出 24 kHz 单声道 WAV。
- [可导入工作流](https://github.com/T8mars/T8-penguin-canvas/blob/v3.5.8/docs/workflows/seed-tts-3-0.json)已通过实网出音与隔离画布验证。

Windows x64 提供 NSIS 安装包和自动更新。Apple Silicon Mac 以同一 Release 中实际发布的预览资产为准；预览包为 ad-hoc 签名，未经 Apple 公证。
