# v3.3.4 画布创作体验与平价模型

- 素材集新增“素材灵感板”：分组、移动/缩放/旋转、布局预览、撤销重做、比较和保存；布局不改变模型输入顺序，也不移动原工作流节点或删除源素材。
- 图片编辑支持保留原图和编辑版本、版本对比与继续编辑；画板可编辑输出版本，不覆盖原有图层。图片编辑器按需加载，关闭时释放资源。
- 新增独立“3D世界”节点：导入本地 SPZ、Gaussian PLY、SPLAT/支持的 KSPLAT，浏览镜头、保存视角并输出构图截图；沿用现有资产和运行记录。它不是网格编辑器，暂不提供在线世界生成。
- Story 可打开既有分镜/剪辑草稿，或显式从当前结果创建新草稿，不覆盖已有手动剪辑，也不重新生成媒体。
- 修复编辑弹窗内保存、编辑结果落图、快捷键与焦点衔接，保留归档只读和原有运行检查。
- 去掉节点松手后恢复的背景模糊/文字祖先滤镜，节点文字不再因拖动状态自动变模糊。
- 贞贞的平价AI小屋：图像“香蕉2”新增 `zhenzhen-image-nb-pro-lowprice`、`zhenzhen-image-nb-2.1-lowprice`；音频“Seed Audio”新增 `doubao-voice-clone`、`doubao-seed-icl-2.0`，支持训练音色接续合成。旧节点、默认来源和已有模型不变，提供九份无凭据工作流。

画布体验142/142专项测试、完整开发画布保存/重开/本地运行、28组主题与窄屏检查通过；四模型已有8/8真实任务和完整产物解码证据，本轮不重复付费生成。此前低内存全量类型检查失败记录保留，正式构建另行核验；不承诺真实大场景性能或用户显卡稳定性。

Windows x64 提供 EXE、blockmap、latest.yml。Mac Apple Silicon 从同正式 Tag 构建，仍为 ad-hoc 签名、未 Apple 公证预览，仅 GitHub 额度不足可延期。安装升级、受影响用户环境、实体GPU、真实RH及F8–F10按 `owner-approved-post-release-v3.3.4` 后补，不记通过；正式包与自动更新资产完整性检查不可延期。
