# T8 Penguin Canvas v3.0.3

本版完整承接 v3.0.2 的 Wan 3.0、主题/英文界面、悬浮工具、Output 自适应和大画布性能更新，并修复 macOS 正式发布对 annotated Git Tag 的固定源码校验。

## 修复

- Mac 发布源校验现在同时读取远端标签对象与 `refs/tags/<tag>^{}` peeled commit，优先将真实提交与 `HEAD`、`T8_RELEASE_TARGET` 绑定。
- 新增 annotated tag、lightweight tag 和缺失引用的回归测试；不会因 annotated tag 对象 SHA 与提交 SHA 不同而误拒绝正确源码。
- v3.0.2 的 Windows 自动更新资产已正常发布；Mac 尝试在任何构建或上传前失败关闭。v3.0.2 标签保持冻结，本修复使用新版本 v3.0.3，不移动、不覆盖旧标签或资产。

## 沿用更新

- Wan Video Tab 新增 8 个 Wan 3.0 I2V/R2V、Global/Prime 精确模型与无凭据工作流，8/8 均已真实生成、下载及解码验证。
- 修复新节点白天模式黑色外壳、英文界面内置中文残留和左侧重复悬浮工具。
- OutputNode 提供自适应/自由/比例视图和按需原图查看器；大画布提供性能档、组代理、离屏重节点冷壳、轻量边和稳定性证据器。
- RH/FAL 开发制作器目录仅在 DEV 环境合并，生产包安全扫描保持严格，相关源码、名称和稳定类型不进入用户包。

## 平台说明

- Windows x64：NSIS 安装包、blockmap、`latest.yml`。
- macOS 12+ Apple Silicon：DMG、ZIP、`latest-mac.yml`。未配置 Developer ID 时为 ad-hoc 签名技术预览，首次打开需在 Finder 右键选择“打开”；Intel Mac 暂不支持。

## 证据边界

用户授权先发布，反馈用户安装、多设备协作、F8–F10 与安装升级证据按 `owner-approved-post-release-v3.0.3` 后补，延期不等于通过。测试、构建、加密、运行时、NSIS、provenance、sealed recovery、固定 Tag/target、Windows/Mac 自动更新资产完整回下载和 Latest 等技术门禁均不可延期。
