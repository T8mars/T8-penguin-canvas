# v3.5.2 · 创作助手与本地安装修复

- 修复创作助手结果已经提交到画布，却提示“来源节点不存在”的问题。发送和查看会先同步结果所在版本，保留同期本地编辑，再定位节点。
- 结果同步暂时失败时，可再次点击“已发送·查看”；只重新读取结果，不重复生成或放置节点。刷新后仍可查看已发送结果。

- 修复本地安装和火山素材目录刷新等非生成维护操作完成后，被误记为输出失败的问题；维护完成不归档旧素材，也不虚构 Provider 调用。
- 更新六项 GitHub 问题的处理进展；未得到受影响设备确认的问题继续跟踪。

最终专项及相邻回归 84/84、完整开发版 Electron 画布五项与持久化运行终态验证通过，进程正常退出且无残留。测试安装使用本地引擎接口夹具，真实模型安装和受影响 Mac 仍待现场复验。
