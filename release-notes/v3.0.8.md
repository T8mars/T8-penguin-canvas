# T8 Penguin Canvas v3.0.8

本版集中改善火山引擎素材库节点的选材与本地导入体验，避免大量素材自动铺满画布，同时保留稳定、可继续接入下游的类型化输出。

## 火山素材选择

- 最多 15 个已选素材统一显示在节点内的有界横向预览栏，不再为每个素材自动生成一个“输出素材”节点。
- 预览栏支持逐项删除和一键清空，图像与视频可直接确认选中内容；临时签名预览只保留在当前内存中。
- 原有 image/video/audio 具名输出和稳定 `asset://` 引用继续保留，可直接连接下游节点。
- 旧版本已自动创建的输出节点只在完全可证明未被使用时清理；用户移动过或已有下游连接的节点不会被删除。

## 本地文件导入火山

- 图像、视频和音频可在火山素材节点内选择本地文件，并选择 API 设置中已启用的云上传目标作为中转。
- 文件先进入受控本地上传，再由既有 COS、OSS 或 WebDAV 目标取得公网 URL，最后调用火山 `CreateAsset` 导入素材库。
- 中转地址必须允许火山服务端公开读取；画布只保存中转目标 ID，不保存本机路径、云端凭据、临时公网 URL 或签名预览。

## 兼容性与证据边界

v3.0.7 及更早的火山素材状态、持久导入任务、Provider、默认渠道和模型、旧画布、历史工作流、主题、双语、MiniMax Music3、Windows/macOS 与性能能力均保持不变。反馈用户安装、多端协作、F8-F10 与安装升级证据按用户授权在发布后补充；测试、构建、加密、运行时、`app.asar` 启动合同、NSIS、provenance、sealed recovery、固定 Tag/target、自动更新资产和远端完整性技术门禁不得延期。
