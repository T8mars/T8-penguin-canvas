# T8 Penguin Canvas v3.1.2

本版继续完整保留 v3.1.1 及更早全部节点、模型、工作流、Provider 协议、MiniMax Music3、Veo Omni 1.1 和旧画布数据，重点让创作对话、本地化生产、大量素材与长时间运行更可靠。

## 新增与更新

- Creator Agent 采用极简 V2：界面只保留六步进度、自然对话、三个真正不同的下一步、当前生成确认、对话内图片/视频和右上角模型设置。每轮正式回复恰好调用一次用户选择的真实 LLM，不使用机械模板冒充成功，也不显示费用。
- Creator Agent 能在用户否定生成、只评价、限定修改、明确图片/视频类型和中英文表达下保持真实意图；图片与视频结果支持恢复、重做和 exactly-once 发送画布，历史媒体不会因刷新消失。
- 多语言本地化大师按“素材 → 翻译 → 配音 → 交付”推进，支持按语言/批次恢复翻译、归档后恢复语言、逐句审阅与单句重配；IndexTTS 2.5 五语许可、离线运行、声音合成和交付边界继续保持。
- 输出素材与画布放置架不再静默只保留最近 60 项；折叠时显示 5 项，展开后每次继续加载 20 项，全部已生成资产均可访问。
- Story 与单节点运行使用稳定提交身份并合并重复启动，避免同一镜头因重复事件被提交多次；失败后的短冷却只阻止连击，不影响用户稍后明确重试。
- 只有 queued/running 的活动 Run 会钉住其全画布快照；终态 Run 继续保留运行证据，但释放快照容量，避免长时间使用后因历史 Run 累积出现“SQLite 临时存储空间不足”。

## 验证边界

- Creator Agent 真实 Provider 验收覆盖完整需求、授权代决策、关键歧义、限定修改、选中文字、否定生成、只评价、风格纠错、明确媒体类型和英文创作；独立评审五项均为 5/5。
- 自动回归覆盖 Creator Repository / LLM / Route / Action / Run 恢复 / 前端 / 双语、Story 稳定提交、输出素材完整访问、Run 快照容量、TypeScript、i18n、能力同步和生产构建。
- Windows 正式包通过私有前后端、后端加密、双运行时、Electron 原生依赖、NSIS、`app.asar` 启动合同、自动更新清单、provenance、sealed recovery 和远端完整回下载门禁；macOS Apple Silicon 从同一固定 Tag 构建 ad-hoc 签名技术预览并进入同一 Release。
