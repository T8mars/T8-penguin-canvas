# T8 Penguin Canvas v3.1.0

本版把创作、跨语言交付和 Veo 低价视频能力统一带入桌面端自动更新，同时完整保留 v3.0.9 及更早版本的节点、默认渠道、旧画布与工作流。

## 新增与更新

- Creator Agent“作品化”：正式创作必须完成真实 LLM 调用；作品文档、版本、字段差异与锁定、素材接地、建议、工具预览/批准/执行和交付证据绑定到同一作品生命周期。
- 多语言本地化大师：支持剧本、SRT/VTT、音视频输入，上下文翻译、术语/保护词、逐句审核、角色音色，以及 IndexTTS 2.5 中/英/日/西/阿五语本地配音、字幕、换轨、QC 和交付清单。
- 视频节点 Veo TAB 新增 `zhenzhen-video-g-omni-1.1-flash-lowprice`：支持 4/6/8/10 秒、720P/1080P/4K、16:9/9:16，以及文生、单首帧、三图参考、单视频参考四种模式。
- 新增四份无凭据 Veo Omni 1.1 示例工作流；默认渠道与模型继续为贞贞的平价AI小屋 / `bytedance/doubao-seed-2.1-pro`。

## 验证

- Veo Omni 1.1 已真实提交一次最低规格任务，成功下载 1280×720、4.01 秒 H.264 MP4，并通过 FFprobe 与 FFmpeg 全片解码。
- 多语言本地化完成四次真实 LLM 翻译、中文恒等分支及 IndexTTS 2.5 五语真实推理、解码、ASR 质量门与重启复用。
- Creator Agent 完成真实 LLM、受控 Chromium、工具批准执行和物理媒体交付验证。
- Electron 发布继续执行固定源码、加密后端、双运行时、原生模块、NSIS、`app.asar` 启动合同、自动更新清单、完整回下载、固定 Tag/target、Windows 与真实 macOS arm64 同源门禁。
