# v3.3.3 平价小屋 Mai 图像

- 图像节点“贞贞的平价AI小屋”新增 Mai Tab：`mai-image-2-6` 与 `mai-image-2-6-flash`；原有模型、默认来源、旧节点和端口保持不变。
- 支持文生图、单图编辑与最多五张有序参考图；保留重复参考槽，超限提示而不截断，WebP/GIF 经上传器转换为真实 PNG。
- 文生图提供 1K/2K、自动画幅、自定义比例与精确像素；有参考图时隐藏尺寸项，由上游决定输出尺寸。固定单张 PNG，不混入 Seed、mask 或其他模型参数。
- 增加 Bing 联网检索开关，默认关闭；继续复用媒体最低 15 分钟超时、原任务 GET 恢复、可信下载及原子落盘，不重复付费提交受理不明任务。
- 提供[六份可导入工作流](https://github.com/T8mars/T8-penguin-canvas/blob/v3.3.3/docs/mai-image.md#六份可导入工作流)，不含密钥、任务身份或产物 URL。

两个模型各有文生图、单图编辑、双图参考共 6/6 真实任务成功，六张 PNG 完整下载解码；135/135 专项回归、49/49 后端检查通过。联网检索、2K、自动/自定义比例及五图极限只完成离线合同验证，不声称逐组合实网或效果评测。

Windows x64 提供 EXE、blockmap、latest.yml。macOS Apple Silicon 使用同正式 Tag，仍为 ad-hoc 签名、未 Apple 公证预览，仅 GitHub 额度不足可延期。安装升级、完整端到端 UI、用户现场及 F8–F10 按 `owner-approved-post-release-v3.3.3` 后补，不记通过；打包和自动更新资产技术校验不可延期。
