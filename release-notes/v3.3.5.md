# v3.3.5 Strata 本地 LLM

- API设置的扩展平台新增“Strata本地服务”预设，读取实际服务的模型、上下文和视觉能力；连接仅查询元数据，不加载模型。原有来源与旧节点参数不变。
- LLM支持本地文本、多轮、图片问答、真正的增量流式、非流式和停止；视频仅显式抽帧，不包含音轨。支持显式采用1024输出token/none思考的本地推荐参数。
- 同机可用无Key模式，局域网需Bearer认证；同源串行排队，执行全链路最长3分钟。失效/停用来源、断流、模型变化或能力不足明确失败，不自动切云端、换模型或重交请求。
- 修复异步连接旧回包覆盖新设置、取消后误采纳结果/成功状态、保留来源ID误走云端、ScriptMaster输出预算及图片压缩预算等8项审查发现的问题。
- ScriptMaster、Story文本分析、提示词增强、翻译和批量打标复用同一适配器；Creator、原生视频/ASR、引擎启停管理暂不纳入。

315/315限定回归和最新完整开发画布16项隔离操作通过，测试进程正常退出且无残留。前轮真实Strata文本/视觉/停止验证通过；本轮冷启动遇到上游HTTP503/WinError5，用户因其他人在使用暂缓排查，本版不操作Strata进程，也不宣称该问题已修复。LAN、其他GPU、安装升级与大型真实任务未验收。

Windows x64包含EXE、blockmap、latest.yml。Mac Apple Silicon同Tag构建，仍为ad-hoc签名、未Apple公证预览，仅GitHub额度不足可延期。外部现场及F8–F10按`owner-approved-post-release-v3.3.5`后补，不记通过；正式包和自动更新资产完整性验证不延期。
