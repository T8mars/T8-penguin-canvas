# v3.5.7 · Anima 文生图与多图编辑

- 平价小屋的图像节点新增 **Anima**，包含 `Anima-v1-t2i`。支持 8 个画面比例，默认 1:1；不接参考图。
- 新增一份[可导入工作流](https://github.com/T8mars/T8-penguin-canvas/blob/v3.5.7/docs/workflows/anima-v1-t2i.json)，文生图已实网生成并完整解码。
- 平价小屋 `zhenzhen-image-gk-v15-edit` 支持最多 5 张参考图。
- 平价小屋 MiniMax H3 换角标准档与 Token 档支持最多 3 张参考图，按原顺序提交。

Windows x64 提供 NSIS 安装包和自动更新。Apple Silicon Mac 以同一 Release 中实际发布的预览资产为准；预览包为 ad-hoc 签名，未经 Apple 公证。
