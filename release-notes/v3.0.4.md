# T8 Penguin Canvas v3.0.4

本版把用户提供的火山引擎素材插件能力重构为核心原生独立节点，并完整承接 v3.0.3 及更早版本的全部画布、Provider、模型、工作流、主题、双语和性能能力。

## 新增：火山引擎素材库

- 新增独立“火山引擎素材库 / Volcengine Assets”节点，复用高级 API 设置中既有的火山引擎 AK/SK，不在节点、画布或前端状态中保存密钥。
- 支持素材组浏览与创建、素材分页与类型筛选、公开 URL 导入、单素材详情、本地标签，以及最多 15 个 Active 素材的批量选择。
- 选中素材按图像、视频、音频输出到具名端口，同时保留聚合结果，便于直接接入既有生成节点。
- 预览使用的临时签名 URL 只保留在当前 UI 会话，不写入画布；持久状态保存稳定素材 ID、素材组、筛选、标签和选择。
- `asset://` URI 仅在明确选择火山引擎 Provider 时按原始 ID 透传，其他 Provider 不接受该内部引用。

## 安全与兼容

- 采用核心后端的有界 Action 白名单与 HMAC-SHA256 签名；签名计算包含规范 Host，但实际 Chromium/Node 请求不手写 `Host` 请求头，避免系统网络栈的 forbidden-header 错误。
- 公开 URL 导入在付费提交前拒绝本机、私网、保留地址、`data:` 与内部 `asset://` 地址，并限制请求/响应体大小。
- 本版没有引入可执行任意第三方 CommonJS 的通用插件宿主；原插件中不完整的前端入口、密钥回显和后台轮询未进入核心包。
- 白天/黑夜主题和中英文界面均使用核心设计令牌与节点目录；默认渠道、默认模型、旧画布字段和历史节点不迁移。

## 平台说明

- Windows x64：NSIS 安装包、blockmap、`latest.yml`。
- macOS 12+ Apple Silicon：DMG、ZIP、`latest-mac.yml`。未配置 Developer ID 时为 ad-hoc 签名技术预览，首次打开需在 Finder 右键选择“打开”；Intel Mac 暂不支持。
