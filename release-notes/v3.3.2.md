# v3.3.2 平价小屋 Topaz 视频修复

- 视频节点“贞贞的平价AI小屋”新增独立 Topaz Tab，模型 `Topaz-Upscale-LowPirce`；已有默认、来源、端口和本地 Topaz 节点不变。
- 支持一个本地 MP4（最大 50 MiB）或公开 HTTP(S) 视频直链；直链直接交给 Provider，不在本应用预下载重传。
- 分辨率提供 720p、1080p、2K、4K，修复模型提供 Ultra、Max、High、Medium、Low；默认 1080p / Max。保持原比例，分辨率档位不承诺固定输出高度。
- 复用媒体至少 15 分钟超时、原任务恢复、完整结果安全落盘；受理不明和下载失败不自动重复付费生成。
- 提供[两份无凭据可导入工作流](https://github.com/T8mars/T8-penguin-canvas/blob/v3.3.2/docs/topaz-video-upscale.md#两份可导入工作流)。

一次真实 720p / Low 本地 MP4 任务成功，产物完整下载解码；157/157 前端及协议回归、42/42 后端用例及单独 10/10 能力检查通过。其他参数组合及直链为离线合同验证，未逐一付费生成；不声称修复质量评测或完整历史输入草稿支持。

Windows x64 提供 EXE、blockmap、latest.yml；macOS Apple Silicon 同正式 Tag 构建，仍为 ad-hoc 签名、未 Apple 公证预览，仅 GitHub 额度不足可延期。浏览器端到端、安装升级、用户现场及 F8–F10 按 `owner-approved-post-release-v3.3.2` 后补，不记通过。
