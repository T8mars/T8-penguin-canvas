# T8 Penguin Canvas v3.2.5

## 画布管理与归档

- 新增“管理全部画布”大窗口，工作中/已归档筛选、名称或 ID 搜索、置顶、最近修改/最近打开排序及有界分页列表。
- 画布可归档、只读查看并恢复；归档不删除素材或释放磁盘。当前画布先保存并确认，运行中、受理不明或保存冲突时拒绝归档；不取消任务、不创建替代空画布。
- 归档同库持久化、备份和数据路径迁移保留；数据库正式升级至 schema33，schema32 身份和恢复保护不变。旧版本不能直接打开升级后的数据库，不要手工覆盖或删表降级。

## 仅新建节点的默认来源

- 设置可分别为后续空白通用图像（含编辑）和视频节点选择 AI 工坊、平价 AI 小屋或软件原默认，提供两项同时设为平价小屋的快捷操作。
- 现有节点、复制、导入、模板、历史和显式来源/模型不自动更换；专用/复合节点、LLM 和音频不受影响。缺少渠道 Key 不偷偷换渠道，保存偏好不触发付费生成。
- 同一初始化合同覆盖适用菜单、选区与 Agent/Creator 创建入口，计划预览前固定配置，原任务恢复不受后续全局偏好影响。
