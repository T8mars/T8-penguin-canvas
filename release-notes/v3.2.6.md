# 贞贞的无限画布 v3.2.6

## 更新内容

- 修复 RunningHub 图片、视频、音频输入被当成旧文件名枚举、导致素材上传前就被拒绝的问题。普通 RH、钱包、超市和工具箱制作器共享修复；真正的选项仍按应用返回的完整值校验，已有画布输入不改写。
- 图像节点“香蕉2 → 贞贞的AI工坊”新增 `gemini-nano-banana-2.1`。旧默认模型、尺寸、比例和参考图参数不变，沿用现有提交与查询链路。
- 继承 v3.2.5 的画布归档管理和仅新建节点的全局默认来源；不自动替换旧节点来源、不删除归档素材。

## 验证与边界

真实 RH 元数据、素材上传、一个应用任务及结果已验证；新模型文生图、图生图均成功并完成结果下载、解码与查看。此证据不代表所有 RH 应用或安装版已完整验收。

启动慢仍待反馈，本版没有修改启动逻辑。用户安装升级、旧画布、反馈现场与 F8–F10 证据按维护者授权后补，不算作通过；正式包及自动更新资产必须通过完整校验。

## 安装

Windows x64 提供 EXE、blockmap 和 `latest.yml`。macOS Apple Silicon 同源包完成后提供 DMG、ZIP 和 `latest-mac.yml`；仅实际 GitHub 额度不足时可延期。

Mac 仍为 ad-hoc 完整性签名技术预览，未使用 Apple Developer ID、未公证。首次安装请在 Finder 中右键应用并选择“打开”，不得视为 Apple 已认证包。
