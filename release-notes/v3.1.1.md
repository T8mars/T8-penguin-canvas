# T8 Penguin Canvas v3.1.1

本版是 v3.1.0 的双平台打包热修，完整包含 Creator Agent“作品化”、多语言本地化大师和 Veo TAB 的 `zhenzhen-video-g-omni-1.1-flash-lowprice`，不回退任何旧节点、旧画布、Provider、工作流、MiniMax Music3 或默认平价小屋 2.1 模型。

## 新增与更新

- Creator Agent 正式创作继续强制真实 LLM，作品文档、版本、字段锁/差异、素材接地、建议、工具批准与交付证据保持同一生命周期。
- 多语言本地化大师继续提供上下文翻译与 IndexTTS 2.5 中/英/日/西/阿五语本地配音、字幕、换轨、QC 和交付清单。
- 视频节点 Veo TAB 包含 `zhenzhen-video-g-omni-1.1-flash-lowprice`，支持文生、单首帧、三图参考、单视频参考四种模式和四份无凭据工作流。
- 修复 macOS 打包时 `auxiliary-models.json` 被两个 extraResources 来源写入同一目标而触发的 `EEXIST`；固定清单只随加密后端整目录进入包，Worker 与下载器继续作为独立本地化运行时资源进入包内。

## 验证

- macOS 失败原因来自真实 `macos-15` arm64 workflow 日志，不是猜测；新增的双平台资源去重回归和本地化运行时回归均已通过。
- Veo Omni 1.1 已真实提交一次最低规格任务，成功下载 1280×720、4.01 秒 H.264 MP4，并通过 FFprobe 与 FFmpeg 全片解码。
- Creator Agent、多语言翻译和 IndexTTS 2.5 五语真实链路继续沿用已完成的脱敏实测证据。
- Windows 与真实 macOS arm64 从同一不可变 v3.1.1 源码和 Tag 重新构建，并执行自动更新清单、远端完整回下载、固定 target 与 Latest 门禁。

反馈用户安装、多端协作、F8-F10、真人听感盲评和安装升级证据按 `owner-approved-post-release-v3.1.1` 后补；延期不等于通过，任何技术发布门禁均不得延期。
