# T8 Penguin Canvas v3.0.2

本版补齐 Wan 3.0 视频模型，并集中修复白天/黑夜主题、英文界面、重复悬浮工具、Output 自适应显示和大画布资源占用。现有默认渠道、默认模型、旧画布、81 个节点、MiniMax Music3、Seedance、Hailuo、Flux、Grok、Hunyuan 3D、Lyria / Flow Music、FlashVSR、即梦 CLI 和 v3.0.0 及更早能力全部保留。

## Wan 3.0

- 视频节点现有 Wan Video Tab 新增 `wan-3.0-global-i2v`、`wan-3.0-global-r2v`、`wan-3.0-i2v`、`wan-3.0-r2v`、`wan-3.0-prime-i2v`、`wan-3.0-prime-r2v`、`wan-3.0-global-prime-i2v`、`wan-3.0-global-prime-r2v`。
- I2V 与 R2V 的参考素材、时长、分辨率、比例和 Prompt 规则在前端、Provider 与代理三层付费前校验，不静默改写模型或素材。
- 保存 8 份无 API Key 配套工作流；8 个模型均逐一真实提交成功，输出完整下载并通过 FFprobe 探测和 FFmpeg 全量解码。

## 主题、英文界面与节点交互

- 新增节点和大型工作台改用主题变量，白天模式不再保留黑色固定外壳，夜间模式保持原有对比度。
- 英文模式覆盖应用外壳、Electron、错误信封、81 节点目录、核心节点与大型工作台；用户文本、Provider 内容、Prompt、模型 ID 和持久化枚举不被误翻译。
- RH/FAL 开发制作器的英文目录和可见文案改为 DEV 专属分层，生产 bundle 继续由 Electron 安全门确认组件名、中文名与稳定类型名均为 0 命中。
- 清理画布左侧重复堆叠的悬浮快捷工具，保留单一权威入口。
- OutputNode 增加兼容旧画布的自适应/自由/比例显示和按需原图查看器，避免默认加载超大原图。

## 大画布性能

- 增加自动、均衡、高性能三档，可解释地控制组代理、离屏重节点冷壳、轻量连线和画布渲染预算。
- 提供 100/500/1000 节点无副作用夹具和可取消的低频五分钟稳定性证据器；采样不足或资源未回落时失败关闭，不伪造“已优化”。
- GitHub #24 与 #25 继续保持开放，等待真实受影响重画布、安装版资源回落、Provider 英文金路径、全浮层、125%/150%/200% 缩放和读屏验收。
