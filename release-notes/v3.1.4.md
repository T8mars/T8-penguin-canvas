# T8 Penguin Canvas v3.1.4

本版完整保留 v3.1.3 及更早全部节点、模型、工作流、Provider 协议、MiniMax Music3、Veo Omni 1.1、多语言本地化大师、默认渠道和旧画布数据，重点发布 Creator Agent 逐场高质量创作、长剧本连续性与启动低资源收口，并在贞贞的平价AI小屋 Hailuo TAB 加入两个 H3 Max Turbo 视频模型。

## 新增与更新

- Creator 输入框新增唯一轻量“逐场创作”入口。即使用户只给一句短想法，也可显式进入真实 LLM 驱动的高质量逐场链；已有完整剧本则按当前场次逐步推进，不增加独立工作台、复杂表单或费用信息。
- 长剧本使用稳定场次、片段、镜头和实体身份，逐场延续人物、地点、关系、离场状态与全剧风格；重复确认不会跳场，局部修改不重建未受影响内容，刷新或重启后可从同一场继续。
- 每轮正式 Creator 回复继续由真实 LLM 生成，并只保留可直接使用的正文与三个当前可执行建议；相同请求精确恢复，不重复调用 Provider，失败重试有界且不把长期超时变成循环。
- 启动链统一复用同一 `projectRuntime`，以当前文档权威 revision、ReactFlow 和 renderer-interactive 收据判断画布是否可交互；左侧节点只在真正 ready 后解锁，空目录仍可立即新建画布。
- 画布目录仍完整保留大量资产与画布：首屏只读取 50 条，继续按页加载，不以 400 条硬上限换速度。后台轮询在页面隐藏或空闲时暂停并有界退避，RH 工具清单跨节点共享缓存，减少启动期无效请求与资源占用。
- Creator 首屏、顶部控制条安全区、常见窗口与 200% 布局、中文输入法和触控目标继续收口；模型状态读取失败时保留输入和素材，提供单一明确的重试入口。
- Hailuo TAB 新增 `hailuo-h3-max-turbo-t2v` 与 `hailuo-h3-max-turbo-i2v`。两者均要求非空提示词、5–15 秒和小写 480p/768p；T2V 使用六种固定比例且拒绝参考素材，I2V 必须首帧、可选尾帧且不发送比例。两份无凭据工作流随版提供。

## 已核实

- 逐场模式真实测试由 `qwen/qwen3.7-max` 生成 600 字可拍单场，只落一场并保持用户限制；`qwen/qwen3.8-max` 独立严格评审为 9.0/10。长剧本另由 `zhenzhen/gk-4.6` 完成四个真实 LLM 回合，三场导入、当前场修改、新人物、隔场复用、离场状态、全剧风格与重启恢复均通过。
- Hailuo H3 Max Turbo 两模型各首次提交一次真实任务，均完成终态、下载、FFprobe 与 FFmpeg 全片解码：T2V 为 1,208,275 bytes、832×480、5.184 秒 H.264 MP4；I2V 为 814,661 bytes、480×480、5.184 秒 H.264 MP4。
- 开发验收已覆盖 Creator 长剧本/逐场模式、画布启动就绪、5000 条目录、ProjectDatabase 生命周期、浅深主题、200% 布局、触控仿真、输入法保护、能力同步、双语与生产构建；API Key、任务 ID、签名 URL 和 Provider 原始响应未写入源码、工作流或公开证据。

Windows 正式包必须通过私有前后端、后端加密、双运行时、Electron 原生依赖、NSIS、`app.asar` 启动合同、自动更新清单、provenance、sealed recovery 和远端完整回下载；macOS Apple Silicon 必须从同一固定 Tag 在真实 macOS arm64 runner 构建并进入同一 Release。

反馈用户安装、多端协作、F8-F10、真人自然语言体验、设备级读屏/触控/缩放和安装升级证据按 `owner-approved-post-release-v3.1.4` 后补；延期不等于通过，任何技术发布门禁均不得延期。
