# T8 Penguin Canvas v3.0.7

本版完成 GitHub PR #28 火山素材节点的数据协议逐项审计，并修复旧节点状态在迁移与重载时丢失的问题。

## 修复

- PR 旧版 `volc-asset` 节点保存的 `Processing / Active / Failed` 状态会原样归一为 `processing / active / failed`，不再一律提升为 `active`。
- 旧画布迁移后仍保留最多 15 个已选素材及其 ID、名称、类型、标签、状态和稳定 `asset://` 引用。
- 只有 Active 素材进入 image/video/audio 具名输出；处理中或失败的素材可以保留在选择记录中，但不会继续进入下游生成。
- 节点重载、标签保存和再次运行继续保持同一状态边界。

## PR #28 承接结论

PR 的前端入口引用了未随提交提供、仓库中也不存在的 `src/components/nodes/VolcAssetNode`，并且其 Chromium 请求显式发送 `Host`，因此不能直接合并。核心原生 `volcengine-assets` 继续承接素材组、素材分页/详情、公开 URL 导入、本地标签、持久任务、最多 15 项混合选择、三类输出、稳定引用和 AK/SK 后端边界；任意 CommonJS 插件宿主、路径/响应泄露与进程级常驻轮询仍不进入安装包。

## 兼容性与证据边界

默认渠道、默认模型、节点身份、旧画布、历史工作流、主题、双语、MiniMax Music3、Windows/macOS 能力及 v3.0.6 和更早功能均保持不变。反馈用户安装、多端协作、F8-F10 与安装升级证据按用户授权在发布后补充；测试、构建、加密、运行时、`app.asar` 启动合同、NSIS、provenance、sealed recovery、固定 Tag/target、自动更新资产和完整远端下载技术门禁不得延期。
